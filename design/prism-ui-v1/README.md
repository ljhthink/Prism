## 打开方式

双击 `index.html`（纯静态，无需服务器、无需构建）。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部屏幕平铺 + 动效示例 + 现状/新版对照 + 三配色 |
| `prototype.html` | 单机可点击流程 |
| `screen.html?screen=…&theme=…&sheet=…&cap=…` | 单屏渲染，供逐屏评审或截图 |

参数：`theme=warm|cool|ink`、`sheet=<id>`、`cap=mcp|skills|memory`、`kb=<库名>`、`qq=on`。

## 触控与可读性

- 视觉尺寸保持紧凑（能力开关 36px、行内小按钮 36px、分段 43px），但通过 `::after` 扩展**热区到 ≥ 44px**，不影响布局。
- 文本对比度（暖石墨）：`text` 15.1:1、`dim` 7.2:1、`faint` 4.8:1、`accent` 8.2:1，均达 WCAG AA。
- 键盘可遍历，`:focus-visible` 有 2px 琥珀描边。

## 生产实现注意

- **开关不要整页重渲染**。Compose 中把开关状态提在行内（`remember` / 局部 `collectAsState`），只让该行重组；若整页 `LaunchedEffect(state)` 重算，`animate*AsState` 会从头播，观感等同没有过渡。
- 运行态动画只在真实运行时启用；`isTyping` 结束后立即停止循环动画，避免空转耗电。
- 语音呼吸环与波形在 `prefers-reduced-motion` / 降低动效开关下停止。
