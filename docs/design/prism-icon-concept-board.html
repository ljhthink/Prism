02 · Icon Concepts · 三方向
主推 · 三棱镜折射

Concept A · Refraction

光从左上顶点射入，经棱镜内折射后分光为靛蓝紫/青/薄荷光谱带射出 —— 一个平台，多元能力。
备选 · 极简线框

Concept B · Minimal

仅一条极简棱镜线框 + 一点入射光与一束薄荷折射光，最大留白，工具感与克制感最强。
备选 · 六束能力之光

Concept C · Six Beams

棱镜将一束光分光为六道光谱 —— 对应六位一体能力：BYOK / RAG / MCP / Skills / 记忆 / 跨 App。
