# 联网深度调研

## 何时使用
用户要求"调研"、"深入了解"、"对比分析"、"查一下最新的"时启用；
简单事实查询（今天日期、单位换算）不需要本策略，直接单次搜索即可。

## 与普通搜索的区别
| | 普通搜索 | 深度调研 |
|---|---|---|
| 搜索次数 | 1 次 | 2-4 轮多角度 |
| 来源要求 | 可单来源 | 关键结论双来源 |
| 输出 | 直接回答 | 结构化调研报告 |

## 使用示例
用户：「调研一下 2026 年主流 Android 端侧 LLM 方案，我想选型」
助手：拆解为①主流方案有哪些 ②各自性能/内存占用 ③开源许可证对比 ④真机实测口碑，逐项搜索后输出调研报告（核心结论 + 详细调研 + 来源列表 + 不确定项）
